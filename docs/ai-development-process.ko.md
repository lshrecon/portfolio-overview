## BassLab: 직접 연습하며 느낀 불편을 개선하기

기초 훈련과 내 연주 돌아보기를 한곳에서 하기 위한 개인 제작입니다. 저는 문제 설정, 필요한 기능과 조작 흐름 정리, 실제 조작·녹음을 통한 동작 확인, 수정 내용 지시를 했고 코드 구현은 생성 AI에 맡겼습니다.

**사용하며 불편 발견 → 요구사항으로 정리 → AI에 구현·수정 요청 → 직접 조작하며 확인**하는 흐름으로 단계적으로 개선했습니다.

### 개발 과정

아래 다섯 단계는 기능과 구조의 변화입니다. 앱 전체를 다섯 번 다시 만들었다는 뜻은 아닙니다.

| 단계 | 문제·바꾼 내용 | 확인할 수 있는 구조·기능 |
|---|---|---|
| 2025년: Streamlit·librosa | 내 연주를 기준 리듬과 비교하고 싶음 | 녹음 파일과 초 단위로 직접 입력한 기준 시각 비교 |
| 다음 시도: FastAPI·React | 화면과 분석 처리 분리 | 업로드 화면과 분석 API. 이때는 녹음 분석이 중심 |
| 2026년: PWA | 분석뿐 아니라 매일 기초 훈련도 하고 싶음 | 청음·음정·화성·리듬·복합 훈련, 미션과 연습 기록 |
| Windows 녹음·분석 | 브라우저에서는 녹음 지연이 일정하지 않았음 | C++·WASAPI로 녹음하고 지연 측정값과 설정 저장 |
| 스코어 연결 | 연습할 프레이즈를 초 단위로 입력하기 불편함 | 줄·프렛·리듬을 악보 격자에 입력하고 녹음·분석·다시 듣기로 연결 |

### 변경 사례: 초 단위 직접 입력에서 악보 입력으로

최초 분석 도구에서는 비교할 리듬을 초 단위로 직접 입력했습니다. 연습하고 싶은 짧은 프레이즈를 쉽게 지정하기 위해 악보 격자로 입력하는 조작을 요구사항으로 정하고, 편집·저장한 악보를 녹음 과제로 연결했습니다.

앱 본체 화면은 한국어입니다. 아래 설명은 이미지에 보이는 조작과 결과를 안내합니다.

① **악보 입력:** 줄·프렛·리듬을 격자로 지정합니다.  
② **연습 조건 맞추기:** 마디 수와 BPM을 함께 저장하고 녹음 과제로 사용합니다.  
③ **다음 조작으로 연결:** 입력한 악보에서 연주 녹음과 결과 확인으로 이어집니다.

![BassLab 악보 입력 화면](../assets/basslab/score-editor.png)

① **과제와 녹음 연결:** 저장한 악보와 녹음 결과를 확인합니다.  
② **후보와 근거 확인:** 음 후보, 예정 위치, 시작 시각 판단을 구분해 표시합니다.  
③ **해당 구간 다시 듣기:** 결과를 정답으로 단정하지 않고 실제 소리와 대조합니다.

![BassLab 녹음 결과 화면](../assets/basslab/recording-results.png)

### 무엇을 확인했나

다섯 가지 기초 훈련에 더해 직접 입력한 악보를 녹음·다시 듣기로 연결하는 흐름을 만들었습니다. 2026년 10월 11일에는 2마디·80 BPM·예정 타격 14개의 악보를 사용한 녹음 3건이 저장됐습니다. 약 2분 동안 연속으로 진행한 스코어 연결 동작 확인입니다.

이미지는 실제 앱의 사본을 조작하며 촬영했고, 결과 화면에는 저장된 녹음 결과를 사용했습니다. 각 장면은 별도로 촬영했으며 이 촬영 때 새로운 악기 녹음을 하지는 않았습니다.

Windows 전환은 녹음 지연을 다루는 방식의 개선입니다. 타이밍 분석 정확도를 입증한 것은 아니며, 2026년 9월 30일 벤치마크는 미리 정한 기준을 충족하지 못했습니다. 현재는 자동 채점 대신 다음 연습에서 확인할 위치를 찾는 자료로 결과를 사용합니다.

## 금융 뉴스 RAG: 혼자 전 과정을 진행한 개인 프로젝트

2025년 LLM 강좌 수강 중 목적 설정, 뉴스·ETF 가격 데이터 수집, LangGraph 처리 흐름 설계, 구현, 결과 확인, 발표까지 혼자 진행했습니다. 구현에는 생성 AI를 활용했습니다. 멘토의 조언을 받아 뉴스를 찾는 것에 더해 가격과 출처까지 확인할 수 있는 보고서를 만드는 방향으로 정리했습니다.

| 시점 | 처리와 확인 내용 |
|---|---|
| 2025년 제작 | 질문 정리 → BM25·벡터·Naver 검색 → 통합·재순위화 → 가격·과거 유사 사례 연결 → 설명문 생성. 수치는 pandas로 계산하고 LLM은 검색어 재작성·설명문 생성에 사용 |
| 2026년 추가 정비·재검증 | 생성 AI의 지원을 받아 저장 데이터로 재실행. 현재 공개한 검색·가격 결과는 BM25 → BGE-M3 실행이며 LLM을 호출하지 않음. 검색 순서에 점수가 반영되는지, ETF별 가격 날짜가 맞는지 확인 |

현재 공개 결과는 2025년 당시의 LangGraph 실행 자체가 아닙니다. 기사·ETF·가격 날짜·계산 결과를 동일 실행의 기록으로 따라갈 수 있는 형태로 공개했습니다.
